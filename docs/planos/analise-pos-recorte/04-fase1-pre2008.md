## 1. Pergunta que a fase responde

Para **cada polígono AUAS** do recorte: a antropização já era visível **antes do marco
de 22/07/2008**?

## 2. Como responde (resumo do que já existe)

| Etapa | Implementação |
|---|---|
| Polígonos | `extractAuasPolygons(clippedGeometries)` → `AUAS-0001…`, `geometryHash`, área, bbox |
| Cenas | 6 por polígono: L5 2003, 2004, 2005, 2006, 2007 + SPOT 2008 |
| Janelas de visão | `W2003_2005` [2003,2004,2005] · `W2005_2007` [2005,2006,2007] · `W2007_2008` [2007,2008] |
| Visão | `qwen/qwen3.6-27b`, ≤3 imagens, `reasoning_effort: none`, JSON validado |
| Decisão | `reduceAuasPolygon()` / `reduceAuasAggregate()` — determinístico |
| Texto | `deepseek-v4-pro`, com fallback determinístico |
| Retomada | `createFileCheckpointStore(jobId)` |

Status por polígono (`PolygonPre2008Status`):

```
ALERTA_PRE_2008              antropizado já em 2003, ou transição entre 2003 e 2007
SEM_EVIDENCIA_PRE_2008       série completa e utilizável, sem transição
INCONCLUSIVO_NO_MARCO_2008   a única mudança aparece entre 2007 e SPOT 2008
INCONCLUSIVO                 cena faltando, nuvem, conflito, JSON inválido
```

Agregado do imóvel (`PropertyPre2008Status`): alerta se ≥1 polígono alerta;
inconclusivo se nenhum alerta mas ≥1 inconclusivo; sem evidência só se todos conclusivos.

## 4. Contrato de saída (já implementado — não mudar sem versionar)

`AuasPre2008AnalysisV2` (`backend/analise-pos-recorte/types.ts:136`), resumido:

```ts
{
  schemaVersion: 2;
  rulesVersion: "auas-pre2008-v1";
  jobId: string;
  status: PropertyPre2008Status;
  pre2008Alert: boolean;
  confidence: Confidence;
  summary: { polygonCount, alertCount, inconclusiveCount, noEvidenceCount,
             totalAuasAreaHa, alertAreaHa };
  sources: { required: string[]; used: string[]; missing: string[] };
  polygons: AuasPolygonResult[];   // status, evidenceKind, observedInterval, sceneIds…
  scenes:  AuasScene[];            // layer, ano, sensor, imageSha256, qualidade
  windows: AuasWindowRun[];        // modelo, tokens, requestId, observação
  report:  { model, markdown, evidenceRefs };
  limitations: string[];
  startedAt; completedAt;
}
```

A Fase 2 consome deste objeto: `polygons[].polygonId`, `polygons[].geometryHash`,
`polygons[].status` e `completedAt`. Nada mais.

## 5. Frase obrigatória de saída

Quando `pre2008Alert === true`, a UI, o SSE, o relatório e o PDF precisam exibir
literalmente:

```
Evidência de desmate/antropização anterior a 2008
```

acompanhada de ano/intervalo observado, confiança, cenas usadas e limitações — nunca só
como campo técnico interno, nunca trocada por "sem evidência" no resumo da propriedade.
(Exigência do plano-mãe da Fase 2, §0.)

## 6. Não mexer

- Nas janelas de visão, no redutor e nos schemas: estão validados e testados.
- No significado de `INCONCLUSIVO_NO_MARCO_2008`: mudança entre L5 2007 e SPOT 2008
  **não** prova de que lado de 22/07/2008 o evento caiu. Continua inconclusivo, e a
  Fase 2 **não** pode reclassificá-lo como pós-2008 sem evidência de 2009 em diante.
